'# 🎮 Jogo da Velha em React

Um clássico **Jogo da Velha** desenvolvido com **React**, utilizando componentes funcionais, **JSX** e os Hooks principais do React (`useState` e `useEffect`). Este projeto foi construído para praticar lógica de programação, gerenciamento de estado e estilização no ecossistema React.

---

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias e conceitos:

* **JavaScript (ES6+)**
* **React** (Biblioteca principal)
* **Hooks do React:**
    * `useState`: Para gerenciar o estado do tabuleiro, o turno dos jogadores, o vencedor e o histórico.
    * `useEffect`: Para lidar com efeitos colaterais, como verificação automática de vitória ou fim de jogo.
* **JSX** (JavaScript XML)
* **CSS3** (Para estilização e layout responsivo)

---

## 💡 Funcionalidades

* **Modo de Dois Jogadores:** Alternância automática entre o jogador `X` e o jogador `O`.
* **Detecção de Fim de Jogo:** Identifica automaticamente quando há um vencedor ou se o jogo terminou em empate (velha).
* **Indicador de Turno:** Mostra de quem é a vez de jogar em tempo real.
* **Botão de Reiniciar:** Permite limpar o tabuleiro e começar uma nova partida a qualquer momento.
